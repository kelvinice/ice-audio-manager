# Pandora (Prototype)

Native Windows music player inspired by **Vivi Music**, connected to and able to wrap **Ice Audio Manager** while keeping `ice-audio-manager` 100% standalone.

See [../docs/pandora.md](../docs/pandora.md) for full architecture diagrams, feature comparison, and next-step direction options.

## Quick Start (PowerShell)

```powershell
# Build UI + Rust and launch Pandora
.\build.cmd run

# Or run type-check, UI build, and Rust tests
.\build.cmd check
```
